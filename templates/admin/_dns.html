Domain bağlama ({{ b.custom_domain if b is defined and b else biz.custom_domain }})

  1. Railway → servis → Settings → Networking → Custom Domain → domaini ekle (hem alanadi.com hem www.alanadi.com). Railway bir hedef adres verir (…up.railway.app).
  2. Domainin alındığı yerde (GoDaddy, İsimtescil, Natro, Cloudflare…) DNS kayıtlarını aç:
    www → CNAME → Railway'in verdiği adres
    @ (kök) → CNAME/ALIAS destekliyorsa aynı adres; desteklemiyorsa Cloudflare'e taşı ya da kökü www'ye yönlendir.
  3. Railway'de domainin yanında yeşil tik çıkınca (genelde 5-30 dk) SSL otomatik açılır, mağaza o adreste çalışır.
